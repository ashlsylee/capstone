# 6주차 — 논문 제출 완료

1-5주차에 진행한 내용을 정리해 논문으로 제출했습니다.

## 제출 내용 요약

**주제**: LLM 페르소나 에이전트로 실제 상권(동대문패션타운 관광특구)의 방문 인구 구성을 얼마나 재현할 수 있는가

- nvidia/Nemotron-Personas-Korea 페르소나 100만 명에게 "이 상권을 방문하겠는가"를 묻고,
  방문 수락자 500명의 연령·성별·시간대·요일 분포를 서울시 상권분석서비스 실제 유동인구와 비교
- 상권 정보를 단계적으로 추가(시뮬레이션 1·2·3)하고, 대조실험 2건(방문 표현 5종 / 패션 직업군 필터링)으로 오차 원인을 추적

## 주요 결과

| 항목 | 결과 |
|---|---|
| 연령·성별 | 실제와 근접 (성별 MAE 0.4-0.6, 연령 MAE 3.7-4.5) |
| 시간대·요일 | 크게 어긋남 — 토요일 비중 실제 11.7% vs 시뮬레이션 74-83% |
| 상권 정보 추가 | 성별 편향은 반편향 지시문으로 회복, 요일 편향은 거의 그대로 |
| 대조실험 | 동사 표현 변경·패션 직업군 표본 모두 방향은 맞지만 효과가 작음 |

**결론**: 일반 인구 페르소나로는 "누가 오는가"는 잘 재현되지만, B2B 도소매 상권의 "언제 오는가"는
LLM의 '상권 방문 = 주말 나들이' 선입견 때문에 재현하기 어렵다. → 7주차에서는 시간·요일은 실제 데이터로
고정하고 LLM에는 매장 선택 판단만 맡기는 구조로 이어감.

자세한 실험 내용: [`5_capstone_simulation/`](../5_capstone_simulation)
