# 4-2주차 — 상권 유동인구 시뮬레이션 (브랜드 라벨 제외)

4주차에서는 매장 5개에 롯데 계열사 라벨(롯데마트·세븐일레븐·엔제리너스·롯데시티호텔·롯데백화점)을
붙여 진행했다. 이 폴더는 그 라벨링을 뺀 일반형 버전이다. 매장은 업종명 그대로(마트·편의점·카페·
호텔·백화점) 두고, 이 문서에서는 매장 구성 자체보다 "가상인간에게 방문 여부를 물어보는 방식이
실제 유동인구를 얼마나 잘 재현하는가"라는 원래 질문에 집중한다.

## 상권 개요

| 항목 | 내용 |
|---|---|
| 상권명 | 동대문패션타운 관광특구 |
| 상권_코드 | 3001493 (서울시 상권분석서비스) |
| 위치 | 서울 중구, 광희동1·2가·을지로6·7가·신당동 일부 |
| 실제 총 유동인구 | 3,054,932명 (2026년 1분기 추정) |
| 상권 특징 | 패션 도소매 특화, 낮시장·밤시장으로 나뉘어 사실상 24시간 운영되는 도매상권 |

## 무엇을 어떻게 진행했는지

가장 먼저 한 일은 아무 부가 정보 없이 페르소나(나이·성별·직업·거주지)만 가지고 "이 상권을
방문할지, 방문한다면 언제"를 gpt-5.4-mini에 물어보는 것이었다(`visit_simulation.py`, 5,000명
질의, 841명 방문 수락). 결과를 실제 유동인구 통계와 비교해보니 연령·성별은 어느 정도 근접했지만
시간대는 크게 어긋났다. 저녁(17-21시)에 절반 넘게 몰렸고, 실제로는 유동인구의 3분의 1 이상을
차지하는 00-11시(자정~오전, 도매상인들이 물건을 떼러 오는 시간대)는 거의 선택되지 않았다.

시간대가 왜 어긋나는지 확인하기 위해 매장 선택 기능을 추가한 v2(`visit_simulation_v2.py`,
20,000명)를 돌려봤는데, 수락률만 16.8%→24.9%로 올랐을 뿐 시간대 문제는 그대로였다. 그래서
두 가지 가설을 세우고 각각을 대조실험으로 분리해서 확인했다. 두 실험 모두 같은 500명(동일
시드)에게 조건만 바꿔 짝지어 물어보는 방식이라, 응답 차이가 순전히 프롬프트 조건 때문인지
표본이 달라서인지 구분할 수 있다.

첫 번째 가설은 "프롬프트에 매장 목록을 나열한 것 자체가 수락률을 끌어올렸을 것"이었다
(`ablation_store_mention.py`). 결과는 매장 언급 여부에 따른 수락률 차이가 16.0%→18.0%
(+2.0%p)에 그쳤고, 카이제곱 검정(1.67, p≈0.20)으로도 유의하지 않았다. 즉 v1→v2 수락률
상승분(+8.1%p)의 대부분은 매장 문구가 아니라 서로 다른 무작위 표본에서 온 것이었다.

두 번째 가설은 "이 상권이 낮시장·밤시장으로 나뉘어 거의 24시간 운영된다는 구체적 사실을
모르기 때문에 시간대 판단이 틀렸을 것"이었다. DDP 행사 정보는 이번 실험에서 의도적으로
빼고, 청평화·동평화·신평화 등 낮시장은 자정~다음날 낮, 아트프라자·apM 등 밤시장은
밤 8시~새벽 5시라는 공개 자료 기반 사실만 프롬프트에 추가했다(`ablation_market_hours.py`,
같은 500명 재사용). 이 조건에서는 시간대 MAE가 13.8%p→11.1%p로 줄고, 00-11시 비중도
2.2%→31.8%(실제 36.5%)로 크게 올라갔다. 매장 목록을 알려주는 것보다 상권 고유의 구체적
사실 정보를 주는 쪽이 훨씬 효과가 컸다는 뜻이다.

## 비교 — 페르소나만 vs 영업시간 정보 반영

아래는 지금까지 실행한 여러 버전 중 양 끝에 있는 두 결과만 비교한 것이다. ① 아무 맥락 정보
없이 페르소나만으로 판단한 최초 결과(v1, 5,000명 질의)와, ② 상권의 낮시장·밤시장 영업시간
정보를 반영해 판단한 최신 결과(대조실험 2의 "정보 있음" 조건, 500명 짝지은 표본)다. 표본
규모가 다르므로 절대 수치보다는 실제값에 얼마나 가까워졌는지 방향을 보는 것이 맞다.

### 연령대

| 연령대 | 실제(%) | 페르소나만(%) | 영업시간 정보 반영(%) |
|---|---|---|---|
| 10대 | 5.6 | 1.2 | 0.7 |
| 20대 | 17.8 | 29.6 | 22.5 |
| 30대 | 21.2 | 22.1 | 18.5 |
| 40대 | 20.7 | 17.4 | 20.5 |
| 50대 | 16.0 | 19.4 | 20.5 |
| 60대+ | 18.7 | 10.3 | 17.2 |

MAE 5.4%p → 3.1%p, 상관계수 0.70 → 0.89. 매장 목록·영업시간 정보 모두 연령 판단을 겨냥한
정보가 아닌데도 함께 좋아졌다 — 프롬프트가 길어지고 상권 설명이 구체화되면서 나이대 추론도
덩달아 정교해진 것으로 보인다.

### 성별

| 성별 | 실제(%) | 페르소나만(%) | 영업시간 정보 반영(%) |
|---|---|---|---|
| 남 | 46.8 | 53.0 | 63.6 |
| 여 | 53.2 | 47.0 | 36.4 |

MAE 6.2%p → 16.8%p로 오히려 나빠졌다. "도매상인이 새벽에 물건을 떼러 온다"는 설명이
LLM에게 남성 이미지를 더 강하게 떠올리게 한 것으로 추정된다 — 실제 도소매 종사자 성비와는
무관하게 프롬프트 표현이 만든 편향일 가능성이 크다.

### 시간대

| 시간대 | 실제(%) | 페르소나만(%) | 영업시간 정보 반영(%) |
|---|---|---|---|
| 00–06 | 17.0 | 2.6 | 31.1 |
| 06–11 | 19.5 | 0.8 | 0.7 |
| 11–14 | 16.2 | 24.1 | 15.9 |
| 14–17 | 16.5 | 18.9 | 10.6 |
| 17–21 | 19.1 | 51.5 | 38.4 |
| 21–24 | 11.6 | 2.0 | 3.3 |

MAE 14.2%p → 11.1%p로 개선됐지만, 상관계수는 0.38 → 0.38로 그대로다. 00-11시 합계
(실제 36.5%)에 훨씬 가까워졌다는 점에서는 분명한 개선이지만, 그 안에서 자정~06시로만
쏠리고(31.1%, 실제 17.0%) 06-11시(오전)는 여전히 거의 선택되지 않는다(0.7%, 실제 19.5%).
프롬프트의 "자정", "새벽 5시"라는 구체적 시각 표현에 반응해 그 시각 근처로만 몰린 것으로
보이며, 17-21시 쏠림도 그대로 남아있다(38.4%, 실제 19.1%). 상관계수가 그대로인 것도 같은
이유 — 특정 구간의 절대 오차는 줄었지만 6개 구간 전체의 상대적 패턴(어디가 많고 적은지의
순서)은 크게 달라지지 않았다.

## 결론

페르소나 정보만으로는 연령·성별은 어느 정도 맞지만 시간대처럼 상권 고유의 구조적 특성이
필요한 부분은 재현하지 못한다. 매장 목록을 나열하는 정도의 정보는 수락률에 거의 영향을 주지
않았고(대조실험 1), 상권의 실제 운영 구조에 대한 구체적 사실을 주는 것이 시간대 정확도 개선에
훨씬 효과적이었다(대조실험 2). 다만 그 개선도 완전하지 않아서, 프롬프트에 등장한 특정 시각
표현 주변으로만 쏠리는 경향이 남아있고, 성별처럼 원래 문제 없던 지표가 새 정보 때문에
오히려 나빠지는 부작용도 있었다. 즉 상권 특화 정보를 추가하는 것은 방향은 맞지만, 어떤
표현으로 얼마나 구체적으로 넣느냐에 따라 다른 지표에 의도치 않은 영향을 줄 수 있다는 것도
같이 확인됐다.

## 실행 방법

```bash
pip install openai python-dotenv pandas pyarrow
# .env.example → .env로 복사 후 OPENAI_API_KEY 채우기

python visit_simulation.py --target 999999 --max-agents 5000 --batch-size 25
python visit_simulation_v2.py --target 999999 --max-agents 20000 --batch-size 25
python ablation_store_mention.py --n 500 --batch-size 25
python ablation_market_hours.py --n 500 --batch-size 25
python expand_30day.py
```

각 스크립트는 기존 결과 파일이 있으면 이어서 진행(누적)한다. `ablation_market_hours.py`는
`ablation_store_mention.py`와 동일 표본(seed 99)을 사용하므로 두 결과가 직접 비교 가능하다.
